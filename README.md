## About me

I am a Computer Programming student at Ondokuz Mayıs University in Samsun, Türkiye.

My public work sits at the intersection of developer tooling, web security, automation, AI-assisted engineering, and computational biology. I care about explicit scope, deterministic behavior, useful tests, readable documentation, and releases that do not promise more than the evidence supports.

AI is part of my workflow, but not an autopilot. I own the scope, technical decisions, validation, release process, and direction of each project.

## How I work

- Prefer small, testable releases over vague feature piles.
- Keep security tools deterministic and make false-positive behavior visible.
- Treat AI-assisted development as supervised engineering with reviewable evidence.
- Separate a working prototype from a validated scientific or production claim.
- Keep public documentation useful, bounded, and honest about unfinished work.
